# normspan

Norm HTML/Markdown span fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/normspan/

## Install / run

```bash
git clone https://github.com/theworker02/normspan.git
cd normspan
node src/cli.js
node --test
```
